# UAV Genetic Algorithm — Multi-Drone Disaster Coverage Planning

An Artificial Intelligence project that uses a **Genetic Algorithm (GA)**
to plan flight routes for three UAVs (drones) performing a search-and-rescue
mission over a 20×20 grid containing no-fly zones, hazard areas, and
high-priority disaster targets.

## Problem Statement

Three drones must fly from fixed starting positions to search a disaster
zone. The mission must simultaneously:

1. **Maximize area coverage** — sweep as many cells as possible
2. **Maximize target detection** — visit priority cells with sensors on
3. **Minimize energy consumption** — save battery
4. **Minimize flight time** — reach survivors fast
5. **Minimize hazard exposure** — avoid danger zones

Balancing five competing objectives across three coordinated drones is a
combinatorial optimization problem. A Genetic Algorithm is well-suited
because it explores many candidate route plans in parallel and improves
them generation by generation without needing a differentiable objective.

## Chromosome Representation

Each chromosome encodes a complete 3-drone mission:

| Field | Description |
|-------|-------------|
| `waypoints` | 3 waypoints per drone (list of (x, y) tuples) |
| `speeds` | Speed multiplier per drone (0.8–1.4) |
| `sensors` | Sensor activation per waypoint (0 = off, 1 = low, 2 = high) |

Concrete flight paths are generated by BFS path-finding between waypoints,
guaranteeing no route crosses a blocked cell.

## Fitness Function

```
F = 0.35·C + 0.25·D − 0.15·E − 0.10·T − 0.15·R
```

Where (all normalized to [0,1]):

- **C** = fraction of reachable cells covered
- **D** = weighted fraction of priority targets detected
- **E** = energy consumed / energy budget
- **T** = flight time / time budget
- **R** = hazard exposure / max possible exposure

A chromosome that generates any invalid route (crosses a blocked cell,
exceeds range limit, unreachable waypoint) is assigned fitness **−10**.

## Genetic Operators

| Operator | Implementation |
|----------|----------------|
| **Selection** | Tournament selection (size = 3) |
| **Crossover** | Per-drone, per-gene uniform + segment crossover (p = 0.5) |
| **Mutation** | Per-gene with rate 0.10 (waypoints, sensors, speeds) |
| **Elitism** | Top 2 chromosomes copied unchanged to next generation |
| **Termination** | 100 generations (or 50 in experiments) |

## Installation

```bash
pip install -r requirements.txt
```

Requires **Python 3.10+** and `numpy`, `matplotlib`.

## How to Run

Generate the best deployment plan and save graphs:

```bash
python main.py
```

Run the sensitivity analysis and random-search comparison:

```bash
python experiments.py
```

| | **3** | **0.142** | 0.018 | 5.7s |
| | 5 | 0.142 | 0.010 | 7.0s |

### GA vs Random Search (5000 evaluations)

| Method | Best fitness | Runtime |
|--------|--------------|---------|
| Genetic Algorithm | **0.1237** | **7.4s** |
| Random search | −0.0308 | 16.4s |
| Improvement | **+501.7%** | 2.2× faster |

## Limitations

- Grid is static; real UAVs face dynamic weather and moving hazards.
- Sensors are modelled as binary detection at waypoints, not continuous.
- BFS path-finding ignores wind, battery curves, and 3D altitude.
- 3 waypoints per drone limits route expressiveness.
